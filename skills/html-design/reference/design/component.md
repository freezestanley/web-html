# 角色：算法化色彩系统生成器

我不需要你直接给我一堆 Hex 码。我需要你构建一套 **“色彩衍生公式”**。
假设品牌种子色是：**`#B35A3D`**（用户可替换）。

## 推导逻辑（高阶色彩科学）：
1. **色相环偏移生成辅助色**：
   - 在种子色色相（H）上 +30° 生成“次要色”，-25° 生成“强调色”。
   - 不要使用补色（180°），那是 AI 偷懒的做法，请使用“分裂补色”方案。

2. **明度阶梯的黄金比例（Perceptual Uniformity）**：
   - 建立 `--color-primary-50` 到 `--color-primary-950` 共 11 个层级。
   - **禁止**线性变化（即禁止简单叠加白/黑）。必须遵循感知均匀曲线（类似 Material Design 的调色板算法）：浅色端（50-300）通过降低饱和度并提高明度实现；深色端（700-950）通过提高饱和度并降低明度实现。

3. **主题自动推导法则**：
   - **暗色模式**：不要直接反转颜色。将背景设定为种子色色相 + 240°（极深蓝灰色）以中和暖色；将白色文字替换为种子色 + 高透明度（15%）的亮色。

## 强制自检机制（Agent 反思循环）：
在输出最终代码前，请先用表格回答以下 3 个问题：
1. *生成的色板是否落入了“蓝/紫/粉”的统计陷阱？*
2. *最浅色与最深色在黑白打印模式下是否能区分？*
3. *如果该配色用在户外强光下，可读性是否达标？*

## 最终输出：
输出完整的 SCSS 变量映射代码，并附上基于该色板绘制的 3 种渐变背景方案（供 Hero 模块使用）。
