# Admin System

## 品牌内核
**精致 · 技术 · 赋能**  
在开发者工具的精确性与现代创意软件的流畅优雅之间取得平衡。界面让复杂的逻辑变得易于管理且富有价值，同时传递出专业可靠与智能创新的品牌感知。

## 视觉风格
融合 **玻璃拟态（Glassmorphism）** 与 **现代企业风（Corporate Modern）**：
- 半透明表面在密集的画布环境中保留上下文信息。
- 通过层次化深度表达界面结构，避免“扁平化”带来的单调。
- 采用内发光与蚀刻边缘营造高触感、高技术的交互体验。
- 整体调性传递专业信赖感与智能响应能力。

## 色彩策略（不含具体色值）
色彩体系以深邃的暗色为基底，旨在减少长时间逻辑搭建时的视觉疲劳。我们不提供固定色号，而是定义语义化的色彩角色，便于主题定制与灵活实现。

### 背景与结构
- **画布背景**：极深色，作为基础层。
- **侧边栏与固定面板**：稍浅的深色，以区分于画布。
- **浮层表面**：使用半透明玻璃效果（详见“深度与层级”）。

### 操作与强调
- **主要操作**：鲜明、高饱和的靛蓝色系，用于按钮、链接和主要交互。
- **AI/智能功能**：紫罗兰色系，用于标识由 AI 驱动的“魔法”特性或增值功能。

### 节点语义色（画布上的认知辅助）
为不同类型的节点赋予特定的色相，帮助用户快速识别其角色：
- **触发器**：翠绿色系 —— 表示流程起点。
- **大语言模型（LLM）**：亮蓝色系 —— 表示核心处理单元。
- **工具/集成**：暖橙色系 —— 表示外部服务或函数调用。

所有文字颜色、状态色（悬停、按压、禁用、错误）均遵循统一的对比度标准，确保可访问性。

## 字体排印

### 主字体 – Inter
- 用于所有界面标签、标题和正文。
- 中性的系统感字体，在高密度数据场景下依然清晰。
- 紧凑的字号缩放，让画布上能呈现更多信息。

### 辅助字体 – JetBrains Mono
- 专用于技术元数据、变量名、节点状态标签以及输入框标签。
- 等宽特性在视觉上清晰区分“普通内容”与“代码/逻辑”。

### 字号层级（基于前端变量）
- `display-lg` – 48px / 加粗 700（标题使用紧字距，呈现高级编辑感）。
- `headline-md` – 24px / 加粗 600。
- `title-sm` – 16px / 加粗 600 / 行高 24px。
- `body-base` – 14px / 常规 400 / 行高 20px。
- `code-label` – 12px / 中等 500 / 行高 16px（使用 JetBrains Mono）。

## 布局与间距

### 流体画布模型
- **画布**：非线性工作区，内置 **24px 点阵网格**，用于节点对齐。
- **侧边栏**：固定宽度 —— 配置面板 **320px**，节点面板 **240px**。
- **节奏体系**：以 **8px** 为基本单位。
  - 面板内边距较宽（20px），防止误触。
  - 列表项内边距较紧凑（8px），最大化纵向空间利用率。

### 响应式断点
| 设备            | 布局表现                                                                 |
|-----------------|--------------------------------------------------------------------------|
| **桌面（≥1440px）** | 完整三栏视图：节点面板 \| 画布 \| 检查器                         |
| **平板（≥1024px）**  | 节点面板折叠为浮动按钮；检查器改为滑出式抽屉                     |
| **手机**            | 编辑器禁用，仅提供只读的 Agent “状态”视图                      |

## 深度与层级

利用玻璃拟态定义三种深度层次：
1. **基础层** —— 纯色画布背景。
2. **表面层** —— 采用 80% 透明度深色背景，并添加 **12px 背景模糊**，用于侧边栏和浮动菜单。
3. **节点层** —— 高对比度的玻璃卡片，带有 **1px 内边框**（半透明强调色），营造“蚀刻”质感。

**阴影**：避免使用沉重的黑色投影，改用 **环境光晕**——大半径（24px）模糊，颜色取自主强调色或节点语义色，使元素看起来柔和地悬浮于画布之上。

## 形状与圆角
统一的圆角处理柔化了工具的技术感：
- **主要容器**（节点、面板）：**12px** 圆角。
- **交互元素**（按钮、输入框）：**8px** 圆角。
- **状态标记**（标签、徽章）：完全圆角（胶囊形），以区别于功能节点。

## 组件规范

### 节点（核心组件）
- 玻璃态卡片，带有 **1px 外边框** 和轻微背景模糊。
- **头部区域**：使用语义色（绿/蓝/橙）作为底色或 **4px 厚顶部边框**。
- 布局：头部（图标+标题）→ 主体（参数区）→ 底部（端口/操作按钮）。

### 按钮
- **主要按钮**：渐变填充主色，顶部带有细微的白色内发光。
- **幽灵按钮**：透明背景，主色描边，适用于画布上的次要操作。

### 画布连接线（边）
- 贝塞尔曲线，**2px 粗**。
- **激活路径**：带有主色光晕的脉冲效果。
- **非激活路径**：较暗的中性色。

### 输入框
- 深色凹陷背景（接近画布底色），**1px 边框**，聚焦时边框变为强调色并带有外发光。
- 标签文字统一使用 **JetBrains Mono** 以增强技术清晰度。

### 标签 / 徽章
- 用于节点标签或模型版本
- 低对比度背景（深色但低于节点本身），避免干扰主要操作。

## 可访问性与交互反馈
- 所有文本与背景的对比度至少满足 WCAG 2.1 AA 级。
- 聚焦指示器清晰可见（输入框、按钮聚焦时显示强调色光晕）。
- 悬停、按压状态通过色彩变量的变体（如减淡、加深）来体现。

## 实现备注
- 所有间距、圆角、字体变量均在 frontmatter 中定义为设计令牌，可直接映射到 CSS 自定义属性或设计工具样式。
- 节点语义色可在实现时映射到通用的主色/辅助色变量，或单独定义 CSS 类。
- 玻璃拟态效果依赖 `backdrop-filter: blur()` 及半透明背景，需注意浏览器兼容性，并为旧浏览器准备回退方案。
