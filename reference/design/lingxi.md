# ZACLAW 项目设计规范 (Design System)

本文档定义了后台管理项目的前端设计语言、组件规范和视觉风格，确保不同模块之间保持一致的用户体验和视觉统一性。

---

## 1. 设计核心原则

*   **功能优先 (Functionality First)**: 界面应清晰展示工具调用状态，例如截图中的步骤列表。
*   **极简主义 (Minimalism)**: 去除不必要的装饰，关注核心操作区域（如左侧对话列表、中间状态跟踪、右侧预览/浏览器）。
*   **一致性 (Consistency)**: 所有的 UI 元素（颜色、间距、字体、图标）必须遵循本规范。

---

## 2. 色彩系统 (Color Palette)

采用科技感与中性色搭配，配合状态指示色。

*   **主色 (Primary)**: `#2D6CDF` (科技蓝 - 用于主要按钮、激活状态、链接)
*   **背景色 (Background)**: `#FFFFFF` (主背景) / `#F5F7FA` (侧边栏及辅助区域)
*   **文本颜色 (Text)**:
    *   主要文本: `#1F2937` (深灰/黑)
    *   次要文本: `#6B7280` (灰色)
    *   辅助文本: `#9CA3AF` (浅灰)
*   **状态指示色 (Status Colors)**:
    *   **成功/已完成**: `#10B981` (绿色 - 对应界面中的 `✅已安装/就绪`)
    *   **进行中/连接**: `#8CFFC3` (亮绿色背景 - 对应右侧的“已连接”标签)
    *   **警告/更新**: `#F59E0B` (黄色 - 对应 `⚠️已更新/已追加`)
    *   **错误/未就绪**: `#EF4444` (红色)
*   **边框颜色**: `#E5E7EB` (浅灰边框)

---

## 3. 排版与字体 (Typography)

*   **字体族**: `Inter`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, Roboto, sans-serif
*   **层级划分**:
    *   **H1**: 24px, Bold (页面大标题)
    *   **H2**: 20px, SemiBold (模块标题，如“新会话…”)
    *   **H3**: 16px, SemiBold (次级标题)
    *   **Body**: 14px, Regular (正文内容)
    *   **Small/Caption**: 12px, Regular (步骤状态说明、标签文字)
    *   **Code**: `Consolas`, `Monaco`, `monospace` (用于显示 `git clone` 等命令行或代码片段)

---

## 4. 布局与结构 (Layout & Components)

### 4.1 三栏布局结构 (Dashboard Layout)
*   **左侧边栏 (Sidebar - Left)**: 固定宽度。包含用户信息、导航菜单 (Skills, 应用中心, 我的个人助理)、折叠面板按钮。
*   **中间区域 (Main Content)**: 弹性宽度。包含**动态步骤执行面板**和**聊天输入框**。
*   **右侧侧边栏 (Panel - Right)**: 固定宽度或根据内容自适应。包含**本地文件系统**和**浏览器预览窗口**。

### 4.2 关键 UI 组件规范

#### A. 状态步骤列表 (Status Steps)
*   **样式**: 列表形式，左侧为图标/序号，中间为文本描述，右侧为状态标签 (Badge)。
*   **状态标签 (Badge)**:
    *   `✅ 已安装` / `✅ 已追 加` / `✅ 已触 发` : 边框色 = 主题绿色，背景透明或浅绿，圆角。
    *   `🔄 依赖就绪` / `⚠️ 已更新` : 使用不同的警示或循环图标。

#### B. 浏览器窗口 (Browser Preview)
*   界面模拟主流浏览器 (Chrome/Safari) 风格。
*   包含顶部 URL 地址栏 (带取消/刷新/收藏按钮)。
*   页面加载错误需以明确气泡形式展示（如截图中的黄色警告 "You are using an unsupported..."）。

---

## 5. 图标 (Icons)

*   保持线性风格（Stroke-based icons），线条粗细建议 `1.5px` 或 `2px`。
*   图标尺寸统一（如 `16x16`, `20x20`, `24x24`）。
*   使用lucide icon

---

## 6. 交互反馈 (Interactions)

*   **悬停状态 (Hover)**: 背景色微变化（`#F3F4F6`）或文字颜色加深。
*   **点击/激活状态**: 主色高亮 (`#2D6CDF`)。
*   **加载/重绘状态**: 步骤状态图标应有转动动画（对应界面中的 `🔄` 图标或工具调用结果展开）。
