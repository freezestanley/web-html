# 多端适配与 UI/UE 基线

本文件只定义无论视觉风格如何都必须满足的体验底线。

## 响应式底线

- 移动优先
- 至少检查 `375px` 和 `1440px`
- 不出现横向滚动
- 文本不裁切
- 图片不变形
- H5 正文建议 `>= 14px`，PC 正文建议 `>= 16px`

## H5 基线

- 触摸目标至少 `44x44`
- 不做 hover-only 交互
- 长列表使用分页或虚拟滚动
- 横竖屏切换后布局不崩
- 注意安全区留白

## PC 基线

- 主内容宽度控制在可读范围内
- 支持键盘 Tab 导航
- 可交互元素有明确 hover / focus 反馈
- 宽表格允许合理滚动，不要强行挤压

## UI 基线

- 颜色、间距、圆角、字号尽量统一
- 信息层级清晰
- 留白足够
- 对比度达标
- 交互组件状态完整
- 异步内容有 loading 和 empty state

## UE 基线

- 首屏关键内容不依赖 JS 才能看到
- 点击后快速给反馈
- 错误提示可恢复
- 多步流程有返回路径
- 具备基本无障碍语义

## 验收抽查

至少抽查:

1. `375px` 布局
2. `1440px` 布局
3. H5 触摸目标
4. PC Tab 顺序
5. 表单错误提示
